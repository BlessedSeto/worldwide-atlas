# worldwide-atlas
A curated collection of 50 fascinating websites for exploring live Earth data, maps, space, science, culture, art, music, and more.

## The site

WorldWide gathers 50 hand-picked destinations across live Earth data, maps and places, space, data and knowledge, libraries and art, music, and science. Search or filter the directory, or use **Surprise me** to jump to a random destination.

## Run locally

This is a static site with no build step or dependencies. Open `index.html` in a browser, or serve this folder with any static web server.

## GitHub Pages

The site is configured to work as a project page under `/worldwide-atlas/`. To enable hosting, open **Settings → Pages** and choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save. GitHub will show the published URL in that section once the first deployment completes.
